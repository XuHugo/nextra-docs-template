# 当金融开始 Token 化，我开始重新思考公链和联盟链

![金融资产 Token 化：开放公链与机构金融网络相互连接](/images/work/chain-tokenization.png)


过去几年，圈内讨论公链时，关注点基本都差不多：TPS 又提高了多少，以太坊 L2 能不能解决性能问题，Solana 的生态能不能继续扩大，下一条高性能公链又会是谁。

这其实和当时 Web3 的业务有关。BTC、ETH、DeFi、NFT 都是 Crypto 原生资产，用户也是 Crypto 用户，所以公链自然追求开放、无需许可、匿名地址和公开透明。

但最近一两年，我越来越觉得这个前提正在发生变化。

稳定币开始进入跨境支付、企业结算和资金管理；美国国债、货币基金、私人信贷开始被 Token 化，BlackRock、Franklin Templeton 等传统机构也在进入这个市场；股票 Token 化也在加速。

这些事情放在一起，其实说明了一件事：**Web3 的业务边界正在从 Crypto 原生世界向传统金融扩展。**

问题也随之而来：如果未来链上承载的不只是 BTC、ETH 和 DeFi Token，而是基金、债券、股票、银行存款，甚至机构之间的大额金融交易，那么过去为 Crypto 设计的公链，还能不能直接照搬？

## 一、RWA改变的不只是资产

RWA 看起来是在“把资产搬到链上”，实际上是在把现实金融背后的一整套规则一起带进来。

BTC 和 ETH 天生就在链上，但一枚代表美国国债的 Token，真正有价值的是背后的国债；一枚基金 Token，对应的是基金份额；股票 Token 背后还涉及证券登记、托管、投资者资格和股东权利。

所以当这些资产进入区块链以后，使用区块链的人也开始发生变化。

过去主要是开发者、Crypto 用户和项目方，现在开始出现银行、基金、券商、支付公司和其他金融机构。

**区块链的使用者变了，链需要解决的问题自然也会跟着变。**

## 二、金融机构需要的链，和Crypto用户不太一样

最明显的是身份。

Crypto 世界里，一个 `0x...` 地址就可以参与大部分链上活动。但如果这个地址要购买几千万美元的基金或者债券，机构必须知道背后是谁、是否完成 KYC/KYB、资金来源是否合法。

所以我们开始看到 ERC-3643 这类受监管资产标准出现。Token 仍然可以运行在 EVM 上，但身份和转账规则已经被加入资产本身。

其次是隐私。

公链最大的特点之一是透明，但金融机构并不希望自己的持仓、交易规模和交易对手全部公开。一家基金如果在链上调仓几亿美元资产，不可能希望竞争对手实时看到自己的操作。

因此机构真正需要的不是“完全透明”，而是**可验证，但不必对所有人公开**。这也是 ZK、选择性披露和隐私交易越来越重要的原因。

另外还有一个经常被忽略的问题：法律最终性。

区块链可以通过共识机制确定交易在技术上的最终状态，但金融体系还需要回答：链上的 Token 到底代表什么法律权利？法院冻结资产怎么办？链上状态和现实资产登记发生冲突怎么办？

到了这里，“代码执行成功”已经不能解决所有问题。

最后是治理。金融基础设施出现严重故障以后，谁可以暂停？谁负责修复？谁决定升级？发生损失谁负责？这些问题在 Crypto 世界里可以交给社区慢慢讨论，但金融机构通常需要更加明确的责任体系。

## 三、我开始重新看待“联盟链”

几年前提到联盟链，很多 Crypto 从业者并不感兴趣，这其实有原因。

早期很多联盟链只是几家公司搭一个共享数据库，没有流动性，没有开放生态，也没有多少真正需要在链上流转的资产，最后很容易变成“为了区块链而区块链”。

但现在情况有些不同。

Canton、Kinexys、Partior，包括 Circle 推出的 Arc，虽然架构差异很大，但都反映了类似的需求：**金融机构希望获得区块链的资产可编程和跨机构结算能力，同时又需要身份、隐私、合规和明确治理。**

这和十年前的企业联盟链已经不太一样。

尤其值得注意的是 Arc 这类网络。它并不是传统意义上的封闭联盟链，而是在开放区块链和机构金融之间寻找新的平衡。

所以未来可能并不是简单的“公链 vs 联盟链”。

在两者之间，也许会出现越来越多面向金融机构的开放网络。

这也是为什么我觉得，与其说“联盟链又回来了”，不如说：**机构金融网络终于开始找到真正适合区块链的业务。**

## 四、业务变了，监管可能也会跟着变

过去 Crypto 监管主要关注 Token 和机构：谁发行稳定币、交易所需要什么牌照、证券 Token 怎么监管、谁负责托管。

但如果未来大量基金、证券甚至银行货币运行在区块链上，监管很难永远只关注 Token。

谁运行网络？谁负责升级？Validator 或 Sequencer 出问题怎么办？金融数据如何跨境？链上的交易最终性和法律上的结算最终性是什么关系？

这些都会逐渐成为问题。

这并不意味着未来“监管机构要监管 Ethereum”，而是说：**当一条区块链真正承担金融基础设施的功能以后，围绕这条网络的运营、治理、数据和结算，也会逐渐进入监管视野。**

## 结语

机构网络的兴起并不意味着公链会被取代。公链提供开放性和全球流动性，机构网络解决身份、隐私和合规问题，未来两者更可能长期共存，并通过互操作协议连接。

RWA 真正带来的变化，也不只是把国债、基金和股票做成 Token。当传统金融机构成为区块链的重要参与者，它们也会把原有的监管、法律和结算规则带进来，并反过来影响链的设计。

**过去是区块链试图改变金融，接下来，金融也会开始改变区块链。**
