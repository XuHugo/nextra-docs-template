# 稳定币是如何失败的：从储备挤兑到死亡螺旋

## 引言：稳定币本质与“足额储备”的迷思

稳定币最容易制造的一种错觉，是让人把“价格暂时等于 1 美元”误认为“它就是 1 美元”。

实际上，链上的 `1` 只是市场此刻给出的报价。它能否在恐慌、拥堵和流动性枯竭时继续成立，取决于一整套系统：储备资产是否可靠，资产能否及时变现，持有人能否顺利赎回，套利机制是否还能运转，以及治理者是否有能力、有意愿处理危机。**稳定币不是天然稳定的币，而是一项需要持续交付的金融服务**。只要这项服务中的某一层断裂，脱锚就可能从一个价格波动，迅速演变成一场集中挤兑。

讨论稳定币风险时，人们最常问的问题往往是：“它有没有 100% 足额储备？”这个问题固然重要，但远远不够。一家发行方可能在会计账面上拥有足以覆盖全部负债的资产，却无法在用户集中赎回时立即拿出现金；储备也可能托管在暂时停业的银行、被冻结的账户，或者缺少清晰法律隔离的主体之下。**资产“存在”、资产“属于持有人”、资产“现在可以使用”，是三件完全不同的事。**

2023 年 3 月的 USDC 脱锚事件就是一个典型提醒。当时 Circle 披露约 33 亿美元 USDC 储备锁在已被关闭的硅谷银行（SVB）。USDC 的问题并不是储备资产凭空消失，而是部分储备在关键时刻失去了即时可得性。链上市场全天候 24/7 交易，而传统银行体系存在营业时间、清算周期和处置程序，两套系统的时间差在周末被无限放大，从而引发严重恐慌。

因此，判断一个稳定币是否真正可靠，不能仅仅看账面总额，还必须继续追问：

- **资产属性**：储备是现金、短期国债，还是信用和期限风险更高的资产？
- **法律隔离**：储备是否与发行方自有资产实现清晰的法律隔离？
- **赎回门槛**：谁拥有赎回权？普通持有人能否直接赎回？
- **时效与响应**：正常时期与压力时期，赎回分别需要多久？
- **冗余机制**：如果银行、交易所或跨链桥中断，系统是否具备备用流动性？

> **核心结论**：真正决定稳定性的，往往不是资产负债表上的总额，而是危机发生时能够动用多少现金，以及多快能够动用。

## 一、 基于国际监管标准的稳定币分类

| 类型 | 典型项目 | 核心锚定与储备机制 | 主要失败模式 |
| :--- | :--- | :--- | :--- |
| **法币储备型** | USDC、USDT、PYUSD、BUSD | 链下现金、银行存款、短期国债 1:1 抵押 | 储备资产信用/期限错配、托管/支付通道冻结、一级/二级市场兑付错配、银行挤兑传染 |
| **加密资产超额抵押型** | DAI、LUSD、GHO、crvUSD | 链上加密资产（ETH、BTC等）超额抵押 + CDP 清算机制 | 抵押品流动性枯竭与价格暴跌、清算系统/拍卖失效、链上拥堵、预言机故障/操纵 |
| **算法 / 内生抵押型** | UST、IRON、ESD、DSD | 算法套利 + 治理/内生代币吸收波动 | 铸造/销毁套利机制失效、内生代币恶性通胀稀释、死亡螺旋、信任彻底崩溃 |
| **对冲型合成美元** | USDe (Ethena) 等 | 现货抵押 + 期货/永续合约等值空头对冲 (Delta Neutral) | 永续合约资金费率长期转负、基差风险（Basis Risk）、CEX/托管方破产、保证金清算与跨场调拨拥堵 |
| **混合型** | FRAX (早期)、CDP + USDC PSM | 部分抵押 + 治理代币 / 外部稳定币池 (PSM) | 多重风险传导与传染、PSM 导致中心化风险转移、危机时刻多重资产相关性归一 |

## 二、 各主流机制的深层失败模式与真实案例分析

### 1. 法币储备型：流动性错配、挤兑与合规中断

法币储备型稳定币的基本结构是发行商持有现金、银行存款或短期国债，并承诺向合格机构提供 1:1 赎回。

**核心风险维度**：
- **储备信用与期限错配**：储备资产未必具有即时流动性。BIS 指出，稳定币负债具有“即时赎回”属性，而储备资产在流动性紧缩时无法在不承受显著折价的前提下快速变现。[BIS：DeFi与稳定币流动性错配](https://www.bis.org/publ/qtrpdf/r_qt2112b.htm)
- **一级与二级市场结构性错配**：只有少数经过 KYC/AML 认证的机构用户可以向发行商直接赎回一级市场资产，绝大多数普通用户只能在 DEX/CEX 等二级市场抛售。一旦二级市场出现恐慌折价，集中兑付需求将压垮一级机制。
- **托管与银行体系风险**：储备资金存放于商业银行，直接继承传统银行业的风险。
- **合规与行政冻结风险**：监管机构可直接要求发行商暂停铸造、冻结恶意地址或封停赎回接口。

**典型历史案例**：
- **USDC 与硅谷银行事件（2023年3月）**：Circle 在硅谷银行（SVB）存有 33 亿美元（约占其储备 8%）的现金。SVB 倒闭后，虽然 Circle 总体未资不抵债，但因该部分流动性暂时无法提取，二级市场恐慌蔓延，USDC 价格一度下挫至 $0.87。[Circle官方说明](https://www.circle.com/pressroom/3-3-billion-of-usdc-reserve-risk-removed-dollar-de-peg-closes)
- **BUSD / Paxos 监管中断事件（2023年2月）**：纽约州金融服务局（NYDFS）命令 Paxos 停止发行新的 BUSD。虽然现有储备足额且允许赎回，但合规指令直接终结了该稳定币的发行生命周期。

> **结论**：法币储备型最典型的故障并非“资产归零”，而是 **市场质疑赎回及时度 → 二级市场折价 → 集中退出与银行挤兑**。

### 2. 加密资产超额抵押型：清算链条与预言机失效

该类稳定币通过在智能合约中超额抵押 ETH、BTC 或 LST/LRT 等加密资产发行（CDP 模式）。

**核心风险维度**：
- **抵押品暴跌与清算时滞**：当抵押资产价格快速穿透清算阈值，若清算速度赶不上下跌速度，系统将产生坏账。
- **区块链拥堵与清算人失联**：极端行情下，网络极度拥堵、Gas 费飙升，清算机器人可能因交易无法压入区块而放弃竞拍。
- **预言机（Oracle）攻击与时延**：预言机喂价延迟可能导致无法及时触发清算；而预言机遭操纵则可能直接导致系统被无套利清空。
- **中心化资产引入的风险传染**：引入 USDC 或 PSM（价格稳定机制）虽然提升了锚定稳定性，但也让去中心化稳定币继承了中心化稳定币的冻结与挤兑风险。[Maker协议白皮书](https://makerdao.com/en/whitepaper/)

**典型历史案例**：
- **MakerDAO "3·12 零元拍卖事件"（2020年3月）**：以太坊价格一日内大跌超 50%，以太坊网络高度拥堵，Gas 费暴涨。大量清算机器人因为设置的 Gas 费过低而无法正常出价，部分清算人趁机以 0 DAI 的竞标价赢得了价值数百万美元的 ETH 抵押品拍卖，导致 MakerDAO 产生约 400 万美元的系统坏账，最终迫使社区发起 MKR 稀释拍卖来填补坏账。

> **结论**：超额抵押并不意味着绝对安全。系统必须保障 **价格发现正常 + 清算人在线 + 链上不拥堵 + 抵押品具备深度流动性**。只要其中一环断裂，150%+ 的抵押率亦无法阻挡坏账形成。

### 3. 算法稳定币：内生资产死亡螺旋

算法稳定币通过算法调节机制，利用内生治理代币或股权代币作为“缓冲垫”吸收稳定币的赎回压力。

**核心失败逻辑**：
1. 稳定币脱锚跌破 1 美元；
2. 用户触发套利机制，销毁稳定币并获得增发的治理代币；
3. 治理代币在二级市场被大量抛售，导致其价格骤降；
4. 治理代币市值缩水后，需要增发呈指数级增长的治理代币才能赎回等额的稳定币；
5. 陷入“稳定币脱锚 → 治理代币恶性通胀 → 治理代币价格归零 → 稳定币彻底无法赎回”的死循环。

**典型历史案例**：
- **Terra / UST 崩溃（2022年5月）**：UST 受到大额抛售脱锚后，算法持续铸造 LUNA 用于赎回 UST。LUNA 供应量从数亿枚狂飙至数万亿枚，价格几近归零。几十亿美元规模的 UST 在几天内迅速崩溃。NBER 论文《Anatomy of a Run》详细记录了这一自我强化的螺旋挤兑过程。[NBER：Anatomy of a Run](https://www.nber.org/system/files/working_papers/w31160/w31160.pdf)

> **结论**：算法稳定币存在根本性的结构缺陷：**稳定币的锚定依赖治理代币的价值，而治理代币的价值又依赖稳定币系统的成功**。IMF 警告指出，此类内生抵押机制是所有分类中脆弱性最高的体系。[IMF稳定币介绍](https://www.imf.org/en/publications/fandd/issues/2022/09/basics-crypto-conservative-coins-bains-singh)

### 4. 对冲型合成美元：对冲仓位与衍生品架构的非对称风险

合成美元（如 Ethena USDe）通常持有加密现货（ETH/BTC）或质押资产（LST），同时在衍生品市场（CEX/DEX）建立等值空头永续合约，以维持 Delta 中性。

**核心风险维度**：
- **资金费率长期转负（Negative Funding Rates）**：在持续熊市或市场看空情绪浓厚时，空头持有者需向多头支付资金费率，导致合成美元基础资产收益率为负，侵蚀本金。
- **基差风险（Basis Risk）与挂钩偏离**：质押资产（如 stETH）与期货标的资产（如 ETH 现货）之间可能发生价格偏离或脱锚。
- **交易所（CEX）与场外托管（OES）风险**：空头头寸存放于 CEX，存在交易所破产、停止提款、API 故障或场外托管清算延迟风险。[Ethena风险说明](https://docs.ethena.fi/protocol-overview/risks)
- **保证金清算与极端行情下的调拨延迟**：当现货价格短时间内剧烈飙升时，空头头寸面临清算风险，需要快速将资产调拨至 CEX 作为保证金。如果区块链拥堵或托管方响应滞后，对冲空头将被强制平仓。

> **结论**：“Delta 中性”仅降低了标的资产的价格方向风险，**绝不等于无风险**。衍生品交易中的对手方风险、资金费率风险和流动性调拨风险依然存在。

---

### 5. 混合型稳定币：风险并非分散，而是传导与叠加

混合型稳定币尝试结合上述多种机制（例如：国债/法币 + 加密抵押 + 治理代币调节）。

**核心失败模式**：
- **上游风险传染**：若系统依赖 USDC 等资产作为 PSM（价格稳定机制）储备，上游资产脱锚将直接传染至本稳定币。
- **危机时刻相关性归一**：在极端市场恐慌中，不同抵押品、对冲策略与治理代币的相关性可能迅速趋近于 1，所谓的“分散化”瞬间失效。

**典型历史演进案例**：
- **FRAX 的机制修正**：FRAX 早期采用了“部分 USDC 抵押 + 部分 FXS 算法调节”的混合架构。但在历经多次市场波动（尤其是 2023 年 USDC 脱锚事件对算法稳定币池的冲击）后，社区认识到混合模式在极端情况下的脆弱性，最终投票通过提案，将其机制彻底转向 100% 足额外部资产抵押。

## 三、 边界辨析：哪些资产不属于传统稳定币？

随着 RWA（真实世界资产）与 Web3 收益型资产的发展，必须清晰界定以下资产与传统稳定币的本质区别：

### 1. 代币化国债与货币市场基金（RWA 基金份额）
- **代表项目**：BUIDL (BlackRock)、OUSG (Ondo)、USDY。
- **本质差异**：属于链上基金份额或债权凭证，随标的资产变动产生 NAV（净资产值）浮动，或需要 KYC/白名单限制。
- **主要风险**：基金 NAV 下降、赎回 T+1/T+2 延迟、二级市场流动性缓冲不足及过户限制。BIS 强调，此类代币继承了传统货币市场基金的流动性错配风险。[BIS：代币化货币市场基金](https://www.bis.org/publ/bisbull115.htm)

### 2. 私人信贷代币（Private Credit Tokens）
- **代表项目**：Centrifuge、Goldfinch 底层信贷池。
- **本质差异**：代表的是链下企业贷款或资产包收益权，高收益来自于承担信用风险与违约风险，并非作为通用支付媒介的稳定币。
- **主要风险**：借款人违约坏账、资产估值不透明、NAV 更新滞后及流动性锁定期。

### 3. 黄金及大宗商品代币
- **代表项目**：PAXG、XAUT。
- **本质差异**：锚定的是特定物理重量的实物商品（如 1 盎司黄金），其美元价格随大宗商品市场波动。
- **主要风险**：实物金库托管、产权法律保护、审计透明度及实物交割门槛。

### 4. 监管视角差异：支付型稳定币 vs 生息型资产 (MiCA 框架)
欧洲联盟 **MiCA (Markets in Crypto-Assets)** 等最新国际监管框架明确将链上稳定资产划分为：
- **电子货币代币 (EMT - Electronic Money Tokens)**：以单一法币计价，承诺 1:1 随时赎回，主要用于支付媒介。
- **资产参考代币 (ART - Asset-Referenced Tokens)**：挂钩多种资产、商品或提供生息机制，监管对其储备资产结构和资本充足率提出了更高的针对性要求。

## 四、 真正通用的稳定币“五层风险分析框架”

综合 BIS、IMF、ECB、美联储及学术界成果，任何稳定币架构均可放入以下五层模型进行系统性解构与风险评估：

| 风险层级 | 核心关注问题 | 典型失效风险模式 |
| :--- | :--- | :--- |
| **1. 资产层 (Asset Layer)** | 储备资产是否真实存在、足额、低风险且独立于发行方？ | 储备资不抵债、坏账、抵押品资产本身崩盘或归零 |
| **2. 流动性层 (Liquidity Layer)** | 在极端市场恐慌下，储备/抵押品能否瞬间无损变现？ | 变现折价、清算流拍、CEX 保证金调拨拥堵、赎回时滞 |
| **3. 兑付层 (Redemption Layer)** | 持有人是否拥有法律保障的、及时的 1:1 一级市场赎回权？ | 赎回通道冻结、一级/二级市场严重折价错配、KYC/AML 阻断 |
| **4. 机制层 (Mechanism Layer)** | 清算、套利、Delta 对冲与预言机能否在极端行情下持续运转？ | 死亡螺旋、预言机延迟/受攻击、资金费率持续负值、清算人失联 |
| **5. 控制与治理层 (Control Layer)** | 谁拥有增发、冻结、升级合约、修改风险参数或紧急暂停的权限？ | 治理攻击、合约漏洞、管理员私钥泄漏、监管行政命令干预 |

### 核心结论

判断一个稳定币体系是否稳健，决不能仅仅看其是否宣称“100% 抵押”，而必须综合考察：

> **储备资产是否独立于稳定币生态本身、是否具有极高的即时变现能力、用户是否拥有清晰且无门槛的法律索取权，以及在流动性黑洞来临时是否存在最终流动性供给者。**
